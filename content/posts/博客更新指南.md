# Yuu Blog 更新指南

## 一、写新文章

在 `content\posts\` 目录下新建 `.md` 文件，开头必须加这段 front matter：

```yaml
---
title: "文章标题"
date: 2026-04-07T10:00:00+08:00
categories: ["tech"]
tags:
  - 标签1
  - 标签2
draft: false
---
```

- `categories`：只能填 `tech` 或 `life`
- `tags`：随便填，可以有多个
- `draft: false` 表示发布，`true` 表示草稿（不会显示在网站上）
- 正文就是普通 Markdown 格式

## 二、部署到网站

### 方法 1：双击 deploy.bat（最简单）

直接双击 `deploy.bat` 文件即可。

### 方法 2：在当前文件夹打开终端运行

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

> 注意：不能直接运行 `.\deploy.ps1`，会被 PowerShell 安全策略拦截。

### 方法 3：自定义 commit 信息

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1 -SourceMessage "feat: 新增XXX文章"
```

```powershell

```
