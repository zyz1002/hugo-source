这篇速记整理了我在搭建站点时用到的命令，方便后来继续维护。

## 常用命令

```shell
hugo new posts/my-first-post.md
hugo server -D
hugo --minify
```

## 目录结构

- `content/`：所有 Markdown 内容
- `static/`：静态资源（图片、CNAME 等）
- `themes/`：第三方主题
